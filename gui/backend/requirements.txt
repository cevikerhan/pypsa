# PyPSA Studio

This directory contains a professional starter GUI for PyPSA with a FastAPI backend and a React + Material UI frontend.

## Overview

- Backend: Python/FastAPI
- Frontend: React + TypeScript + Vite + Material UI
- Visualization: Recharts
- PyPSA integration: opens PyPSA example networks and runs optimization flows

## Quick start

### 1) Backend

```bash
cd gui/backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

### 2) Frontend

```bash
cd gui/frontend
npm install
npm run dev -- --host 0.0.0.0 --port 5173
```

Then open: http://localhost:5173

## Features included

- Dashboard overview with PyPSA metrics
- Power flow and linear optimal power flow execution
- Network composition and topology summaries
- Scenario configuration panel
- Results analysis page
- Backend API for health checks, optimization, and component summaries

## Notes

This is a professional starter that can be extended into a full PyPSA modeling suite with network editor, scenario management, file import/export, and results sharing.
